# Sample Tax Check

Interactive questionnaire for PGG sample shipments (brand side, recipient side, intercompany).
It shows whether to invoice with or without VAT, why a 1 EUR invoice is not the solution,
the economics for PGG, the brand and the recipient, ready-to-use templates and a to-do list.
Results can be downloaded as Excel or copied for documentation.

## Files

- `index.html` – the complete tool (single file, no build step)

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push `index.html` to the repository (root or `/docs`).
2. Repository → Settings → Pages → select the branch and folder.
3. The tool is available at `https://<org>.github.io/<repo>/`.

## Requirements

- A current browser (Chrome, Edge, Firefox, Safari)
- Internet access to `cdnjs.cloudflare.com` for the Excel export (SheetJS 0.18.5)

## Scope

German and UK PGG companies. Not a replacement for tax advice – if in doubt, ask Group Finance.
